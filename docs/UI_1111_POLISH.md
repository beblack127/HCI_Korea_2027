# 11.11-ui1 — 화면·문구 정리

## 적용 범위

요청한 1~4번(문구, 상태 패널 위계, 개발 정보 구분, 시각적 정리)을 적용했다. 시작 화면의 세 예시 주제와 baseline 조건 이름은 유지했다. 정책·판단 기준은 `11.11-v4` 그대로이며, UI 표시 버전만 `11.11-ui1`이다.

## 변경

- `static/ui-copy.js`: 저장된 값의 표시만 정돈한다. 상태 요약의 반복 안내를 줄이고, 관점 변경 문장의 조사를 맞춘다. 추정의 한계는 접힌 도움말에 모았다. 원문·근거·추정·응답·지원 정책을 변경하거나 재저장하지 않는다.
- 상태 패널: 현재 검토 방향 → 최근 변경 → 다음 탐색을 먼저 보여준다. 상세 내용/연구 문제/추가 검토 질문/과거 어려움은 ‘탐색 내용 자세히 보기’, 근거는 ‘이렇게 정리한 이유’, 활동은 ‘탐색 기록’에서 확인한다. 현재 지원이 필요한 경우와 정리 준비 안내는 조건에 따라 표시한다.
- 오류: 사용자에게는 짧은 안내와 재시도 동작을 먼저 보여준다. 원래 오류 원인과 제공자/HTTP 정보는 접힌 ‘오류 정보’에 남긴다. 입력 말풍선과 동일 request_id 재시도는 유지한다.
- 설정: AI 사용 사실과 모델 정보는 유지한다. `.env`와 실행 파일 안내는 접힌 ‘연구자용 연결 정보’에 둔다. ‘AI 지원’ 표시는 사용 모드이며 제공자의 실시간 정상 응답을 보장하는 연결 상태로 표현하지 않는다.
- 장식: WORKSPACE, RESEARCH NOTE와 패널 구분 번호를 제거했다. 추천을 대화에서 가리키기 위한 후보 번호는 유지했다. BASELINE 표시는 변경하지 않았다.
- 시각적 위계: 보조 텍스트 대비와 글자 크기를 정리했다. 기존 둥근 말풍선·입력창·전송 효과·주요 버튼과 어려움 색상은 유지한다.
- 탐색 행동: 버튼 옆에 선택한 주제를 표시한다. 내부 논문 검색은 검색 아이콘, 외부 원문 링크는 ↗로 구별한다. 저장 동작과 알림 문구를 통일했다.

## 검증

- 제안 시스템: Python 148개, JavaScript 33개 통과.
- 로컬 baseline: Python 172개, JavaScript 39개 통과.
- 표시 과정에서 원본 snapshot/역사적 응답이 바뀌지 않는 것, 오류의 기술 정보가 기본 안내와 분리되며 입력과 요청 ID가 유지되는 것을 검사했다.
- 기존 상태 추정·지원·검색·정리 관련 검사도 통과했다. 추정과 지원 코드/프롬프트의 변경은 없다.
- 별도 Chrome 프로필과 QA 서버에서 저장된 합성 응답을 사용해 1800/1440 데스크톱 및 390 모바일 화면을 확인했다. 가로 넘침이 없었고 상세 내용·근거를 펼칠 수 있었다. 제공자 503 상황은 UI에서 모의하여 기본 안내/접힌 기술 정보/재시도/입력 유지를 확인했다. 현재 어려움의 붉은 계열과 3px 강조선도 유지됐다.
- UI만 바꾼 작업이므로 새 실제 LLM 호출은 수행하지 않았다.

## 배포·데이터

기존 `5109`/`5110` 주소, 데이터 폴더, 쿠키와 API 설정을 유지한다. 새 화면은 새로고침 후 적용된다. 이전에 저장된 추정과 응답의 원본은 보존되며, 그 화면 표현에도 표시 전용 문구 정리가 적용된다. baseline에도 공통 UI를 동기화하되 상태 추정의 생성/화면 유입 차단은 유지한다. baseline은 로컬에만 보관한다.
